上传与使用
1. 将两个 .list 文件上传到你的 GitHub 仓库。
2. 在 Loon 的远程规则中添加对应 Raw 地址，策略选择 DIRECT。
3. 或将下面两行合并进现有配置的 [Remote Rule] 段。替换 USER、REPO 和 main 为实际用户名、仓库、分支；不要重复添加配置段。

[Remote Rule]
https://raw.githubusercontent.com/USER/REPO/main/LANDirect.list,policy=DIRECT,tag=局域网直连,enabled=true
https://raw.githubusercontent.com/USER/REPO/main/ChinaDirect.list,policy=DIRECT,tag=国内直连,enabled=true

优先级
局域网直连优先；指定网站代理（包括现有海外域名规则）优先于国内直连；最终兜底在最后。
本文件仅提供直连集合，不包含原 Clash 的海外代理列表、Telegram 策略、节点或 DNS 设置，因此单独导入不等同于迁移整套 Clash 配置。
国内 IP 规则未添加 no-resolve，以保留本地正在使用配置的行为；局域网 IP 保留 no-resolve。
远程列表内不写 DIRECT，由导入时的 policy=DIRECT 指定。
