Loon 国内直连规则 — 自动同步版

更新方式
GitHub Actions 每天 UTC 22:47（北京时间次日 06:47）检查上游；计划任务可能排队延迟。
手动更新：Actions → Sync Loon direct rules → Run workflow。
首次运行已成功：ChinaDirect.list 119817 条、LANDirect.list 160 条；以后以文件头数量为准。
Loon 需要定期更新远程规则，才能拉取仓库中的新版本。
GitHub 可能暂停长期无仓库活动的公共仓库计划任务；发现停更时在 Actions 检查并重新启用。

优先级与范围
局域网直连优先；Bybit 等指定网站代理和海外代理规则应优先于国内直连；最终兜底在最后。
这是直连规则集合，不包含节点、密码、DNS 设置或整套 Clash 策略。
Bybit.list 不在自动更新范围内，保留原文件和手工补充。
国内 IP 允许解析以匹配；局域网 IP 保留 no-resolve；IPv6 使用 IP-CIDR6。

自定义补充
可创建 custom/ChinaDirect.list 或 custom/LANDirect.list，按 Loon 格式写规则（不附 DIRECT 策略）。
支持 DOMAIN、DOMAIN-SUFFIX、IP-CIDR、IP-CIDR6；IP 可附 no-resolve；# 开头是注释。
修改 custom/ 后自动触发合并、去重与发布。不要直接修改根目录生成文件，它们会被上游同步覆盖。
例如：DOMAIN-SUFFIX,example.com

失败保护
每个来源下载最多重试三次，拒绝异常格式和过小列表，规则总数比已发布版本减少超过 20% 时停止。
所有来源通过校验后才生成文件并提交；失败不会发布半份更新。上游有意大幅删减时需人工核实后调整阈值。
只有内容改变才产生更新提交。更新失败可在 Actions 查看日志。
